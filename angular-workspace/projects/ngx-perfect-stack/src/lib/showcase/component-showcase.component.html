Natural Language Feature Specification Cucumber BDD 
Feature: TextFieldControlComponent
  As a user filling out a metadata-driven form
  I want a text field control that adapts to edit and view modes
  So that I can enter data and view formatted values seamlessly

  Scenario: Entering text in edit mode
    Given the TextField is in "edit" mode
    When I enter "Rex" into the input
    Then the form control value should be "Rex"
    And the input should reflect "Rex"

  Scenario: Switching to view mode renders read-only display
    Given the TextField has value "Rex"
    When mode is changed to "view"
    Then the input element is replaced by a read-only text span
    And the text span should display "Rex"

  Scenario: Validation error appearance
    Given the TextField is marked as touched
    And the control has a validation error
    Then the input should have the CSS class "ng-invalid"
    And a validation error label should display "Attribute required"

  Scenario: Decimal scale formatting for Double attributes
    Given the attribute scale is set to "2"
    When I enter "123.456" into the input
    Then the value should automatically format to "123.46"
